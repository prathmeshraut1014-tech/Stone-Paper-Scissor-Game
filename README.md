# 🪨📄✂️ Stone Paper Scissor Game

A simple and interactive **Stone Paper Scissor Game** developed using **HTML, CSS, and JavaScript**. The game provides a fun way to play the classic Stone Paper Scissor game directly in a web browser.

## 📌 About the Project

**Stone Paper Scissor Game** is a beginner-friendly web development project created to practice the fundamentals of:

* HTML
* CSS
* JavaScript
* DOM Manipulation
* JavaScript Event Handling
* Random Number Generation
* Basic Game Logic

The player selects **Stone, Paper, or Scissor**, and the JavaScript logic determines the result of the game.

## 🎮 Features

* 🪨 Stone selection
* 📄 Paper selection
* ✂️ Scissor selection
* 🤖 Computer-generated choice
* 🏆 Automatic winner determination
* 🔄 Interactive gameplay
* 🎨 Simple and user-friendly interface

## ⚙️ How the Game Works

The game follows the standard Stone Paper Scissor rules:

```text
Stone beats Scissor
Scissor beats Paper
Paper beats Stone
```

If both the player and computer choose the same option, the result is a **Draw**.

### Game Flow

```text
        Start Game
             ↓
     Player selects option
             ↓
     Computer selects option
             ↓
       Compare choices
             ↓
       ┌─────┴─────┐
       ↓           ↓
     Winner       Draw
       ↓           ↓
        Display Result
```

```bash

```

Go to the project folder:
